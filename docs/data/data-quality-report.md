## Issues Intentionally Preserved

**181,992 rows with null timestamp/date/time (3.89% of small_matrix)**
- Reason: Timestamps missing in source data — not a data error. `watch_ratio` is never null.
- Action: Preserved. Time-based filtering must account for nulls in Phase 3.

**watch_ratio values > 1.0 (1,514,717 rows, 32.4%)**
- Reason: Users replaying videos produces ratios > 1.0. This is valid behavior by design.
- Action: Preserved. Never filter without Phase 3 analysis.

**22,790 watch_ratio values > 5.0**
- Reason: Extreme replays — plausible, but may indicate anomalies.
- Action: Preserved in Phase 2. Flag for investigation in Phase 3 feature engineering.

**video_id=1225 in item_categories (1 row)**
- Reason: Should have been removed in v2.0. Present in `item_categories` but not in
  interaction matrices. Does not affect training data.
- Action: Documented. Filter in Phase 3 if needed.

**12.63% null captions in kuairec_caption_category**
- Reason: Not all videos have author-provided captions. This is expected.
- Action: Preserved. Imputation strategy deferred to Phase 3.
